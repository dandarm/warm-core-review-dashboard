# Example dataset

Four samples (two negatives and two positives) selected from
`data/label_AMSUcomplete.csv` in the `cnr-isac-wcdetection` project.
These are the first two labelled samples (`unlabelled=0`) of each class
with available images, in the original CSV order.

Identifiers were converted from `Track*/NetCdf_data/*.nc` to `Track*/*.npz`,
the format used by the dashboard. NPZ files are not included.
The 18 images are unmodified copies from
`data/ClimatologyTracks_V01/Track*/Images/`.
Labels are the original dataset labels, not personal review decisions.

This small dataset is intended for testing the interface, not evaluating models.
Image rights remain with their respective owners. A local copy does not
automatically grant a license for public redistribution.
